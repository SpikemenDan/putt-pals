# Engineering rules

The authoritative engineering rules are maintained in
[AGENTS.md](../AGENTS.md).

Technical design is documented in
[ARCHITECTURE.md](../ARCHITECTURE.md).

Gameplay configuration is documented in
[TUNING.md](TUNING.md), and the existing presentation configuration is
documented in [DISPLAY.md](DISPLAY.md).

Do not duplicate operating policies here. When changing an engineering rule,
update AGENTS.md and keep relevant technical documentation consistent.
